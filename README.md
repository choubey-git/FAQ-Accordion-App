# ❓ FAQ Accordion Application

An interactive and responsive FAQ Accordion Application built using **HTML**, **CSS**, and **JavaScript**.  
This project allows users to expand and collapse frequently asked questions with smooth animations and clean UI interactions.

---

## 🚀 Features

- 📂 Expand and collapse FAQ sections
- 🎨 Smooth accordion animations
- 🔄 Rotating arrow icon effect
- 📱 Responsive design
- ⚡ Fast and lightweight
- 🧠 Built using Vanilla JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons
